# Decision log

- **Architecture:** Astro static output with React islands and a lazy-loaded Phaser stage.
- **Content:** Local Markdown collections validated with Zod; no CMS or backend.
- **Localization:** English and Brazilian Portuguese have separate indexable routes.
- **Puzzle:** A voluntary constraint-combination exercise using real portfolio projects.
- **Audio:** Synthesized interface cues, muted by default and activated only by the visitor.
- **Visual thesis:** A high-contrast midnight drafting table with electric index colors, exposed grids, and physical card offsets.
- **Personal data:** Only publicly verified GitHub and LinkedIn profiles are linked; no email is invented.
- **Runtime and security:** Astro 7 on Node 24; the production dependency audit reports zero known vulnerabilities.
- **Review hosting:** OpenAI Sites provides the private prototype URL. A public production host remains a human gate.
- **Analytics:** A provider-neutral, aggregate event adapter is present but remains disabled until the public host and privacy policy are approved.
