# Product brief

## Goal

Present Fernando de Souza Araujo as a hybrid creative technologist who combines game systems, audio, visual communication, and interaction design.

## Audience

The primary audience is hiring managers and collaborators looking for hybrid creative-technology skills. Secondary audiences include game-audio teams, game programmers, and creative web studios.

## Product principles

1. Work is visible before the game.
2. Every case study states the problem, contribution, constraints, process, and evidence.
3. Sound is opt-in and never carries exclusive information.
4. Motion supports orientation and has an equivalent reduced-motion state.
5. The visual language is an original abstract card studio, not an imitation of an existing card game.

## Non-goals

No accounts, combat, collectible economy, backend CMS, compulsory gameplay, contact form, or opaque scoring system.
